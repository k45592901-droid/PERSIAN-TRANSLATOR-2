# مترجم خودکار بازی — نسخهٔ آزمایشی

## امکانات
- انتخاب ناحیهٔ بازی یا کل صفحه
- OCR پیوستهٔ متن انگلیسی هر ۱٫۲ ثانیه
- ترجمهٔ خودکار انگلیسی به فارسی با سرویس آنلاین Google Translate (بدون کلید API)
- پنجرهٔ شناور بدون کادر سفید؛ پس‌زمینه در حالت پیش‌فرض شفاف
- تغییر اندازه و رنگ متن و میزان تیرگی پس‌زمینه
- جابه‌جایی پنجره با کشیدن آن
- خروجی Self-contained برای Windows x64؛ روی دستگاه مقصد نصب .NET لازم نیست

## محدودیت‌های مهم
- **ترجمه در این نسخه آنلاین است، نه آفلاین.** برای ترجمهٔ آفلاین واقعی باید مدل ترجمهٔ انگلیسی‌به‌فارسی به برنامه افزوده شود؛ هنوز در این بسته وجود ندارد.
- OCR از Windows.Media.Ocr استفاده می‌کند و به قابلیت OCR و بستهٔ زبان انگلیسی ویندوز وابسته است.
- متن بازی‌های سریع یا فونت‌های فانتزی ممکن است درست تشخیص داده نشوند.
- بعضی بازی‌های Fullscreen Exclusive اجازهٔ نمایش پنجرهٔ شناور روی بازی را نمی‌دهند؛ حالت Borderless/Windowed مناسب‌تر است.
- سرویس ترجمهٔ آنلاین ممکن است در برخی شبکه‌ها در دسترس نباشد و برای ارسال متن به اینترنت نیاز دارد.
